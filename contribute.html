GÓP GAME · PULL REQUEST

Thêm game vào máy

Mỗi game là một thư mục riêng. Không cần backend hay bước build.

GITHUB REPOSITORY Fork repo ↗
  1. 01

    Fork repo

    Fork trên GitHub, rồi tạo nhánh riêng.

  2. 02

    Tạo game

    Sao chép games/_template/ thành games/ten-game/.

  3. 03

    Đăng ký

    Thêm game và người đóng góp vào games.json.

  4. 04

    Gửi PR

    Chơi thử, ghi nguồn asset và mô tả thay đổi.

Ghi nhận contributor

Thêm tên và username GitHub trong mảng contributors của game để hiện ở trang Contribute.

Asset và tiến trình

Chỉ dùng asset có quyền phân phối; ghi nguồn trong ASSETS.md. Tiến trình lưu cục bộ bằng localStorage.

Chạy thử tại máy

Trong thư mục repo, chạy lệnh rồi mở http://localhost:8000.

python3 -m http.server 8000
